# 스마트팩토리 전력 이상 탐지 및 통합 관제

**제5회 BDAI 채용 연계 데이터 분석 공모전 · green그린그림**  **최우수상 수상**
  [English](README.en.md) · 한국어

13종 설비의 RTU 전력 데이터에서 **어느 설비를, 언제 우선 점검할지** 찾는 프로젝트입니다. 전체 설비를 비지도 모델로 선별한 뒤, 집중 관리 대상의 5초 단위 이상을 IQR, EWMA, Isolation Forest로 교차 분석하고 관제 대시보드에 표시했습니다. 여기서 *이상*은 전기적 관측 패턴에서 벗어난 시점이며, 실제 고장이나 에너지 낭비가 확인됐다는 뜻은 아닙니다.

![스마트팩토리 전력 이상 탐지 대시보드](https://appapppy-smartfactorydashboard.streamlit.app/)

## 프로젝트 개요

| 항목 | 내용 |
  | --- | --- |
  | 데이터 | 13종 설비, 33,696,013건, 19개 변수 |
  | 관측 기간 | 2024-12-01 ~ 2025-04-30, 약 150일, 5초 간격 |
  | 주요 변수 | 3상 전압·전류·역률, 유효전력, 무효전력, 가동 상태, 누적 전력량 |
  | 분석 목표 | 라벨 없는 데이터에서 집중 관리 설비와 점검 시점 선별 |
  | 결과물 | 2단계 탐지 절차 및 Streamlit 관제 프로토타입 |
  
  ## 왜 예측 대신 탐지인가?
  
  처음에는 3상 전압·전류 불평형이 **미래 역률 저하의 선행 신호**일 것이라고 가정했습니다. Logistic Regression, XGBoost, LightGBM을 시간순으로 분리한 데이터에서 비교한 결과, 역률 지연 변수를 포함할 때 ROC-AUC는 **0.63~0.66**이었지만 이를 제거하면 **0.49~0.51**로 떨어졌습니다. 관측된 예측력은 주로 역률의 단기 지속성에 의존했습니다. 분석한 역률 이상 에피소드의 **99.24%**도 단일 5초 관측 시점에 끝났습니다.

따라서 **현재 제공된 변수와 관측 기간에서는 유의미한 선행 신호를 확인하지 못했다**고 판단하고, 현재의 전기적 이상을 탐지하는 방향으로 설계를 바꿨습니다.

## 분석 절차

1. **품질 점검 및 파생 변수:** 수집 공백, 값 결측, 누적 계량기 롤오버, 전압 범위 이탈을 확인했습니다. 보고서 기준 네 항목 모두 0건이었습니다. 분석 시각으로 `localtime`을 채택하고 평균 역률, 3상 전압·전류 불평형률, 무효/유효 전력비 등을 만들었습니다.
2. **1단계 — 전체 설비 스크리닝:** 유효전력, 무효전력, 평균 역률, 전압·전류 불평형률, 무효/유효 전력비의 **6개 지표**로 Isolation Forest를 적용했습니다. 5분 집계 자료 **561,613행**을 분석해 예비건조기(설비 15번)를 집중 관리 후보로 선정했습니다.
3. **2단계 — 5초 단위 정밀 분석:** 예비건조기에 대해 역률 IQR 규칙(`3 × IQR`), 역률 EWMA 관리도(30분 스무딩, `3σ`), **4개 지표**를 입력으로 사용하는 Isolation Forest를 비교했습니다. 짧은 스파이크가 5분 평균에 희석되지 않도록 EWMA에는 5초 원자료를 사용했습니다.
4. **운영 화면:** 설비별 이상률, 모델별 판정, 역률 추이, 시간당 이벤트 빈도와 최근 이벤트를 함께 볼 수 있는 관제 프로토타입을 구성했습니다. 실제 RTU 스트림과 자동 연결된 상용 실시간 시스템은 아닙니다.

## 주요 결과

| 분석 | 결과 | 해석 |
  | --- | --- | --- |
  | 전체 설비 스크리닝 | 예비건조기(15번) 이상률 **1.62%**로 13종 중 1위 | 현장 점검의 우선 후보 |
  | IQR | **20,317개 관측치** (0.78%) | 극단적인 단일 역률값의 기준선 |
  | EWMA | **26,244개 관측치** (1.01%), **25,991개 이벤트** | 시간 순서의 역률 변화를 반영 |
  | 정밀 Isolation Forest | **20,736개 관측치** (0.80%) | 여러 지표가 함께 달라진 시점 포착 |
  | EWMA와 IQR | IQR 탐지 관측치 전부 포함, **5,927개** 추가 | 두 방법의 탐지 범위가 다름 |
  | EWMA와 Isolation Forest | **16,179개** 공통, IF만 **4,557개**, EWMA만 **10,065개** | 서로 다른 후보 시점을 제시 |
  | 고빈도 구간 | 시간당 **10.93건 초과** 기준, **369개 구간** | 점검 우선순위용 운영 기준 |
  
  1단계 이상률은 전체 설비의 **5분 집계 자료**, 2단계 탐지 건수와 비율은 예비건조기의 **5초 관측치**에 대한 결과입니다. EWMA **25,991개 이벤트**는 연속 탐지 관측치를 묶은 수이며, **26,244개 이상 판정 관측치**와 같은 단위가 아닙니다. 2단계 Isolation Forest의 `contamination=0.008`은 IQR과 탐지 규모를 맞춰 비교하려고 설정했으므로, **0.80% 자체는 독립적인 정확도 증거가 아닙니다.** 모델 간 중복 역시 실제 정답률을 뜻하지 않습니다.

## 대시보드에서의 활용

**설비별 이상률 확인 → 해당 시점의 모델 판정 비교 → 반복·고빈도 구간 우선순위화 → 현장 점검 → 조치 전후 비교** 순서로 사용할 수 있습니다. 5초 이상을 모두 즉시 알리는 대신 시간당 빈도와 여러 모델의 일치 여부를 함께 보여주는 운영 방식을 제안합니다. 시간당 10.93건은 평균 7.29건의 1.5배로 정한 **초기 운영 기준**이며, 실제 현장에서는 조정해야 합니다.

## 해석 범위와 다음 단계

- 고장·유지보수 정답 라벨이 없어 탐지된 시점의 실제 원인이나 오탐률을 확인하지 못했습니다. 센서 교정 기록과 현장 점검 결과를 연결해야 합니다.
- 서로 다른 설비의 유효전력이 약 3,009 W로 매우 비슷합니다. 실제 부하 특성인지, 계측 또는 설비 라벨링 구조의 영향인지 검증이 필요합니다. `operation=1` 기록만으로 모든 설비가 실제로 24시간 가동했다고 단정할 수 없습니다.
- 절감 전력량, 전기요금 절감액, 탄소 저감량은 **실측하지 않았습니다**. 개선 전후 전력량과 요금 자료를 비교한 뒤에만 정량화할 수 있습니다.
- 다른 사업장에 적용할 때에는 설비별 정상 범위, EWMA 설정, Isolation Forest 임계값과 알림 기준을 다시 보정해야 합니다. 실제 스트리밍 연결과 모델 재학습 기준도 후속 과제입니다.
